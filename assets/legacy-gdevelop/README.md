# Retained prototype assets

These seven assets were preserved byte-for-byte when the obsolete standalone GDevelop project was retired. They are source assets, not a replacement engine or active runtime dependency.

The former project documented scene setup and third-person controls adapted from [GDevelop’s 3D island terrain example](https://github.com/GDevelopApp/GDevelop-examples/tree/main/examples/3d-island-terrain). The sample island/foliage art was replaced by the user-supplied Lagos Shadow Frontier model and original placeholder avatar/control artwork. That attribution describes the former scene adaptation; it does not grant new redistribution rights for the supplied model. Consult original source/license terms before redistribution.

The island model also remains at `frontend/public/models/lagos-shadow-frontier.glb`. The retired engine scene and its instructions can be recovered from commit `dfbca72` and earlier history.
