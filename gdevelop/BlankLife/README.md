# Blank Life — GDevelop project

Open `BlankLife.json` in the GDevelop desktop editor. The project loads the Lagos Shadow Frontier GLB, spawns a stylized placeholder developer avatar, and includes third-person keyboard/touch movement. Its default scene preset targets budget phones: 960×540, 30 FPS, mobile antialiasing off, dynamic resolution scaling, and no post-processing or realtime shadows. See [`../README.md`](../README.md) for controls and migration notes.
